Day 1 FastAPI 学习笔记

今天的核心不是写很多代码，而是完整跑通一次：创建虚拟环境、安装 FastAPI、写第一个接口、启动服务、访问自动文档。

主题：第一个 FastAPI 应用 项目：my_day01 入口文件：main.py

今日目标

1. 理解虚拟环境 知道 `.venv` 是项目自己的 Python 环境，依赖安装在这里，不污染系统 Python。
2. 跑通 FastAPI 启动服务后能访问 `/`、`/hello`、`/me` 和 `/docs`。
3. 看懂最小代码 理解 `FastAPI()`、`@app.get()`、函数返回字典会变成 JSON。

虚拟环境

创建虚拟环境：

python3 -m venv .venv

激活虚拟环境：

source .venv/bin/activate

安装 FastAPI：

python -m pip install "fastapi[standard]"

确认正在使用虚拟环境里的 Python：

which python
python --version

退出虚拟环境：

deactivate
删除虚拟环境前先确认路径，再执行：rm -rf .venv。`.venv` 本质上就是一个普通文件夹。

今日代码

你今天在 my_day01/main.py 中写了三个接口：

from fastapi import FastAPI

app = FastAPI()


@app.get("/")
async def root():
    return {"message": "Hello FastAPI"}


@app.get("/hello")
async def hello():
    return {"message": "你好，FastAPI"}


@app.get("/me")
async def me():
    return {"name": "liangxin", "content": "fastapi"}
Python 常见风格：顶层函数之间空两行；字典里冒号后面加一个空格，例如 {"name": "liangxin"}。

启动和访问

启动服务：

uvicorn my_day01.main:app --reload

如果要用 FastAPI CLI，更稳的写法是：

python -m fastapi dev my_day01/main.py
地址 作用 预期结果
http://127.0.0.1:8000/ 首页接口 {"message": "Hello FastAPI"}
http://127.0.0.1:8000/hello hello 接口 {"message": "你好，FastAPI"}
http://127.0.0.1:8000/me 个人信息接口 {"name": "liangxin", "content": "fastapi"}
http://127.0.0.1:8000/docs Swagger 自动文档 可以看到所有接口并在线测试

代码逐句理解

  • from fastapi import FastAPI：从 FastAPI 包中导入核心类。
  • app = FastAPI()：创建一个 FastAPI 应用对象，后面的接口都会挂在这个对象上。
  • @app.get("/")：声明一个 GET 请求接口，访问路径是 `/`。
  • async def root()：定义处理请求的函数，浏览器访问 `/` 时会执行它。
  • return {"message": "Hello FastAPI"}：返回 Python 字典，FastAPI 会自动转换成 JSON。

今天遇到的问题

你访问过 /hell0，它返回 404。原因是路径写成了数字 0，而代码里定义的是字母 o：/hello。

你执行 fastapi dev my_day01/main.py 时，如果跑到了系统的 /opt/homebrew/bin/fastapi，可以改用 python -m fastapi dev my_day01/main.py，这样会优先使用当前虚拟环境里的 Python 包。
